A/B-тест новой механики уведомлений для ретейлера

Задача: ретейл-сеть SkyLenta тестирует переход с баннеров в приложении на пуш-уведомления. Нужно на основе данных ответить, действительно ли новая механика повышает конверсию в покупку и средний чек, и оценить финансовый эффект от масштабирования.

Что сделано:

	•	Подготовка данных: очистка и объединение трёх таблиц (заказы, клиенты, справочник торговых точек) в pandas
	•	Статистическое тестирование: написаны функции для t-критерия Стьюдента и критерия Манна-Уитни; проверена значимость различий среднего чека и конверсии между тестовой и контрольной группами
	•	Сегментация: результаты теста рассчитаны отдельно по 66 торговым точкам и по ключевым городам (Москва, Санкт-Петербург)
	•	Бизнес-калькулятор: результаты выгружены в Excel (xlsxwriter) и переведены в денежную оценку — интерактивный калькулятор с входными параметрами (N клиентов, MDE) считает прогнозируемый прирост/падение выручки при масштабировании новой механики
  
Результаты:

	•	На уровне всей компании и в Москве/Санкт-Петербурге — статистически значимый рост и среднего чека, и конверсии в тестовой группе
	•	Из 66 точек 51 прошла проверку на корректность данных; результаты разбиты на положительный / отрицательный / нейтральный исход по p-value
	•	Для точек с недостаточным объёмом наблюдений рассчитано необходимое количество наблюдений для обнаружения эффекта заданного размера (MDE)
  
Инструменты:

Python (pandas, scipy, matplotlib), Jupyter Notebook, Excel (xlsxwriter)

Файлы:

	•	ab_test_analysis.ipynb — весь анализ и статистические расчёты
	•	skylenta_calculator.xlsx — итоговый калькулятор для менеджмента
