Портфолио — София Семенова, аналитик данных
Студентка 4 курса МИРЭА. Прошла курс «Аналитика данных» (Skypro). Ниже — три сквозных проекта на реальных бизнес-кейсах: от сырых данных до статистически обоснованных выводов и рекомендаций для бизнеса.
Проекты:

1. A/B-тест новой механики уведомлений
Python, pandas, scipy (t-критерий, критерий Манна-Уитни), Excel-калькулятор.
Полный цикл: очистка данных → статистическое тестирование → сегментация по 66 точкам → перевод результатов в оценку эффекта на выручку.

2. Анализ транзакций розничной сети
Excel, анализ аномалий, оптимизация нагрузки на серверы, оценка программы лояльности (экономия 12%).

3. Продуктовая аналитика мобильной игры
SQL, Metabase. Продуктовые метрики (MAU/DAU/Sticky Factor), k-factor, когортный анализ выручки.

Навыки:
Python (pandas, scipy, matplotlib) · SQL · A/B-тестирование и статистические тесты · Excel (продвинутый, xlsxwriter, дашборды) · Jupyter Notebook · Metabase · Визуализация данных
