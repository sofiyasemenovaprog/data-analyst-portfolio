Продуктовая аналитика мобильной игры Zombie Revolution

Задача: проанализировать ключевые продуктовые метрики игры, технические проблемы и эффект маркетинговых активностей на основе SQL-запросов к базе данных (Metabase).

Что сделано: 

	•	Рассчитаны базовые продуктовые метрики: MAU, DAU, WAU, Sticky Factor на выборке 3 101 пользователя и 27 161 сессии
	•	Проанализированы технические ошибки сессий в разрезе по ОС
	•	Оценён эффект маркетинговой акции по приросту регистраций
	•	Проведён когортный анализ выручки: сравнение паттернов трат новых и «старых» пользователей
	•	Рассчитан коэффициент виральности продукта (k-factor)
	•	Разработаны и сопоставлены три альтернативных критерия определения «лояльного пользователя» (по рефералам, по сумме платежей, по среднему чеку)
  
Результаты:

	•	97% критических ошибок сессий приходится на iOS (3 262 записи) — сформулирована рекомендация по приоритизации фикса
	•	Маркетинговая акция дала максимум регистраций за весь период (1 544 пользователя)
	•	k-factor = 0.92 — высокий органический виральный потенциал
	•	Выявлена разница в поведении новых и лояльных пользователей, предложена таргетированная стратегия привлечения
